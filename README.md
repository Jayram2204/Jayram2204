## What I'm Building

### Chronicles of Stellar — live mainnet
A Web3 game where **autonomous AI agents act as persistent, on-chain NPCs**, storing state directly on the Stellar blockchain. Ships with Soroban contracts, a Phaser frontend, and agent brains that live and act on-chain.

[![Stars](https://img.shields.io/github/stars/Jayram2204/Chronicles-of-Stellar-?style=flat&color=FFD700)](https://github.com/Jayram2204/Chronicles-of-Stellar-) · [Play the live DApp](https://www.chroniclesofstellar.online/)

### AgentPay — on Monad
An **agent-to-agent settlement layer** using x402 + ERC-7579 modular accounts. Cuts AI billing costs ~96% — turning $50 subscriptions into $2 micropayments with **0.8s finality**. Session-sharded storage unlocks 10,000+ parallel payments at ~$0.006 each.

[![Stars](https://img.shields.io/github/stars/Jayram2204/agentpay?style=flat&color=FFD700)](https://github.com/Jayram2204/agentpay) · [Live dashboard](https://monad-agent-pay-three.vercel.app)

### Synergi Cloud
Decentralized cloud infrastructure for agent-native applications.

### Trustchain (working name)
A **Layer-0 blockchain** I'm building from first principles — evolved from *Synergii* → *Solidus* → *Trustchain*. Ground-up consensus, ledger, and agent-native primitives.
